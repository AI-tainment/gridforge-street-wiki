# GridForge Street Wiki

A static, navigable wiki of every UK sign face, road marking, matrix glyph and piece of
street furniture in the GridForge sources, one page per item, regenerated from the
source trees by one command. Local master copy (Build). **Not published.** Git Ops may
publish it later as a public repo, only after the owner's explicit go.

## Regenerate

    python3 wiki/build.py --out site

`site/` is committed and is the master copy. It is GitHub Pages ready: relative links
only, `index.html` at the root, `.nojekyll`, no server, no web fonts.

Source paths (read-only; nothing is written to them) come from, first match wins:
command-line flags, `GFWIKI_*` environment variables, a gitignored
`wiki/local_config.json` (copy `wiki/local_config.json.example`), or the relative
placeholder defaults under `sources/`. The build stops with a clear message if a source
is missing.

| Flag | Env var | What |
|---|---|---|
| `--atlas` | `GFWIKI_ATLAS` | Signage Atlas checkout: `countries/uk/{signs,markings,furniture}.json`, `site/faces/uk/**.svg` (faces generated by `tools/atlas/render.py`), `tools/atlas/traced.py` SOURCE (parsed with `ast`, not imported), `countries/uk/sources/*`, `qa/UNVERIFIED-SOURCES.md`, `qa/DECISIONS-PENDING.md`, `LICENCE.md` |
| `--matrix` | `GFWIKI_MATRIX` | `<signage-atlas-art>/kit/street_furniture/sign/matrix`: Art's `.war` matrix glyph grids (Spec 019/022), pending sign-off |
| `--art-placeholders` | `GFWIKI_ART_PLACEHOLDERS` | `<signage-atlas-art>/placeholders`: Art's plan batches 10-12 (`MANIFEST.md`, `UNVERIFIED.md`, `faces/`) |
| `--kit020` | `GFWIKI_KIT020` | `<gridforge-art>/020/gf.module.bus_stop_ref.gfkit`: Spec 020 bus stop kit; GLBs are read from inside the `.gfkit` zip (not `_old/`) |
| `--kit020-dir` | `GFWIKI_KIT020_DIR` | `<gridforge-art>/020`: kit folder (tri report) |
| `--look` | `GFWIKI_LOOK` | `<signage-atlas-art>/kit/street_furniture/bus_stop/look`: Art's look pack (NOT FOR SHIPPING until signed off) |

Generated pages never show local absolute paths: each source root is shown as a
placeholder such as `<atlas>`, and any other absolute path as `[local path]`.

`wiki/known_status.json` holds Reviewer ADJUST grades that the atlas data does not carry
yet (each cites its review file). Edit it by hand.

## Content

- Home, category pages (sign families, markings, 2D furniture, matrix glyphs, Art drafts, 3D furniture), one page per item, A-Z index with static-JS search, licences page, and a code section (every generator file rendered as a page and copied raw).
- Item pages: preview (SVG faces; matrix grids drawn as SVG; 3D rendered to PNG), id, name, diagram ref / source page, status, attribution and licence.
- Status labels: Drawn, ADJUST (Reviewer), Placeholder, Unverified source, Pending owner decision, Pending sign-off, Art draft not yet imported, Reference placeholder (Spec 020). Placeholder faces show a banner saying the image is the neutral placeholder, not the sign.
- **Art batches 10-12 decision:** included as their own category, every page labelled "Art draft, not yet imported" (30 drawn) or "Unverified source" (11 with no locatable diagram, no face). They are not merged into the atlas sign pages, which keep showing the atlas' own placeholder until Build imports them.
- **3D previews:** rendered headlessly from the GLB (LOD0) by `wiki/render3d.py`, a numpy z-buffer software rasteriser (flat shading, alpha blend for glazing). Each module/assembly gets two PNGs: the Architect placeholder materials and Art's look-pack base colours (labelled not for shipping). The look-pack page shows Art's existing preview and swatch PNGs (copied, not re-rendered).

## Not included (and why)

- Third-party asset kits elsewhere in the `gridforge-art` tree (Kenney, KayKit, Quaternius, cartoon-city): not street-furniture sources for this wiki, and under their own licences.
- Spec 020 `_old/` (r1, kept for diffing) and separate LOD1/LOD2 renders (LOD files are listed per page).
- The atlas SI PDFs (`refs/`) and the atlas' interactive app (it loads Google Fonts). Only its generated face SVGs are used.
- No Transport typeface or any font file; no location or personal data.

## Determinism

Sorted iteration everywhere, no timestamps or build-time values, fixed camera and image
size (`wiki/config.py`), no randomness. `sys.dont_write_bytecode` keeps `__pycache__` out
of the source trees.

## Checks

Personal names: the build redacts the owner's personal name from any text quoted from
the sources (`redact()` in `wiki/build.py`; source trees are not edited), and
`tests/check.py` fails if the name appears anywhere in `site/` or the tracked files.

    python3 tests/check.py        # (a) twice-regen byte identity + committed site, (b) link check, (c) counts table, no fonts
    sh qa/screenshots.sh          # headless Chrome screenshots into qa/screenshots/

`qa/site.sha256` is the sha256 manifest of the generated tree; `qa/check-report.txt` the last check output.

## Dependencies

Python 3 stdlib, plus `numpy==2.5.4` (BSD-3-Clause) and `Pillow==12.3.0` (MIT-CMU/HPND),
both already on the box (`requirements.txt`; nothing was pip-installed). Screenshots use
the box's Google Chrome headless.

## EPS faces (two build modes)

- **EPS mode** (the atlas has `site/faces-eps/`, which it now commits): sign pages show the official GOV.UK
  face first, with the Crown copyright / OGL v3.0 attribution (`media/signs/*--eps.svg`), then the atlas's
  procedural face as the fallback. The committed `site/` is built in this mode, with the SVGs it needs.
- **No EPS** (`GFWIKI_EPS=off`, or an atlas without `site/faces-eps/`): no EPS links and no Crown notice;
  the procedural face, then the placeholder. `tests/check.py` passes in both modes.
